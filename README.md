✨ About The Project

Pig Game is an interactive two-player dice game with a beautiful black-and-gold design.

The game combines classic gameplay mechanics with modern styling, smooth animations, and a responsive layout.

🌟 Features
🎲 Random dice rolling (1–6)
👥 Two-player gameplay
💾 Score tracking and saving
🏆 Automatic winner detection
🔄 New Game functionality
✨ Smooth animations
📱 Responsive design
🖤 Premium black-and-gold theme
🎮 How To Play
Player 1 starts the game.
Click Roll Dice to roll the dice.
Each roll adds points to the Current score.
Click Hold to save your accumulated points.
Rolling a 1 ends your turn.
The first player to reach 50 points wins automatically.

Note: The game ends immediately when the Current score reaches 50 or more.
